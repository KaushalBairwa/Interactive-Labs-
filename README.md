# Interactive Labs

Free browser-based cybersecurity exercises published through Killercoda.

## Available labs

### Lab 01 — External Attack-Surface Discovery

- Difficulty: Beginner
- Estimated time: 25–35 minutes
- Environment: Disposable Ubuntu browser terminal
- Tasks: 6 verified exercises
- Scope: A controlled target hosted entirely inside the lab environment

Learners enumerate the approved target, discover exposed services, inspect HTTP
metadata, locate hidden content, identify a plaintext legacy service and retrieve
a final flag.

> Use these techniques only against systems you own or have explicit permission
> to test.
