# Suspicious PowerShell Detection

You are a SOC analyst investigating a suspicious Microsoft Office to PowerShell execution chain.

This is a **controlled forensic dataset**. No malware is executed in the lab. You will analyse prepared telemetry from:

- Sysmon process and network events
- Windows Security Event ID 4688
- PowerShell Script Block Logging Event ID 4104
- Wazuh alerts
- A Sigma-style detection rule

Record each answer with:

```bash
lab-submit <task> <answer>
```

Start with the files under `/root/investigation`.
